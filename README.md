# UAU Veículos — Protótipo

Projeto Vite + React pronto para abrir no seu editor (VS Code, etc).

## Como rodar

```bash
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (geralmente http://localhost:5173).

## Estrutura

- `src/App.tsx` — todo o protótipo (site público + admin), igual ao arquivo que você enviou.
- `src/main.tsx` — ponto de entrada que renderiza o `App`.
- `index.html` — carrega as fontes (Space Grotesk, JetBrains Mono, Inter) usadas no design.
